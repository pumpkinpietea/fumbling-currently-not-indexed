## Claude Code v2.1.305 adds sandbox option and fixes tool-search failures {#news-1}

Claude Code v2.1.305 adds a Linux nested-user-namespace option and retries without tool search when providers or gateways reject it. The release also fixes settings and worktree issues.

[Source: Anthropic Claude Code · Updated 2026-10-20 20:46:50 UTC](https://github.com/anthropics/claude-code/releases/tag/v2.1.305)

## Google completes Coral NPU architecture and releases compiler {#news-2}

Google says its Matrix Execution Unit completes the open-source Coral NPU architecture. The IREE/MLIR compiler supports bringing JAX, PyTorch and TensorFlow models to the hardware without custom assembly.

[Source: Google for Developers · Published 2026-10-20](https://developers.googleblog.com/unifying-edge-ai-how-coral-npus-open-standard-brings-portable-energy-viable-intelligence-from-model-to-silicon/)

## Google explains TorchTPU integration with TorchTitan {#news-3}

Google describes TorchTPU's native PyTorch TPU backend and a TorchTitan TPU fork with scaling tools, including SimpleFSDP, Graph Trainer and custom Pallas kernels.

[Source: Google for Developers · Published 2026-10-20](https://developers.googleblog.com/integrating-torchtpu-into-torchtitan-and-optimizing-models-for-tpu/)

## Google announces native PyTorch backends for vLLM and SGLang on TPU {#news-4}

Google announced TorchTPU-powered backends for vLLM and SGLang, with optimized TPU kernels, KV cache management using TPU Sync and disaggregated serving.

[Source: Google for Developers · Published 2026-10-20](https://developers.googleblog.com/announcing-new-vllm-and-sglang-inference-engines-on-tpu/)

## Google Model Explorer adds custom compiler graph debugging {#news-5}

Google AI Edge Model Explorer now supports custom compiler intermediate representations and adapters including TOSA, VGF and PTE, with graph views and per-node traces for debugging.

[Source: Google for Developers · Published 2026-10-20](https://developers.googleblog.com/bringing-visual-graph-debugging-to-custom-edge-compilers-with-model-explorer/)
