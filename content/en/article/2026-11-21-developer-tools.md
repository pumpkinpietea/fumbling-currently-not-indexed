## Codex 0.171.0 adds model options and enables TUI workspace by default {#news-1}

OpenAI's Codex 0.171.0 adds GPT-6.2 Sol and Astra, with Sol as the default catalog selection. It also enables the TUI workspace by default and adds remote noninteractive sessions.

[Source: OpenAI Codex · Published 2026-11-20 00:44:47 UTC](https://github.com/openai/codex/releases/tag/rust-v0.171.0)

## Google extends Agent Anomaly Detection to agents across other clouds {#news-2}

Google says Agent Anomaly Detection now monitors ADK agents on AWS, Azure and on-premises through traces and logs ingested into a Google Cloud project.

[Source: Google for Developers · Published 2026-11-20](https://developers.googleblog.com/agent-anomaly-detection-safeguarding-agents-across-other-clouds/)

## Google explains private Cloud Run MCP connections to Gemini Enterprise {#news-3}

Google published guidance for privately connecting Gemini Enterprise to internal Cloud Run MCP servers using Egress Agent Gateway, Private Service Connect and dual-header OAuth 2.0.

[Source: Google for Developers · Published 2026-11-20](https://developers.googleblog.com/how-to-securely-connect-internal-cloud-run-mcp-servers-to-gemini-enterprise/)

## Google details authentication for custom Gemini Enterprise interfaces {#news-4}

Google explains 3 authentication layers developers must implement for custom Gemini Enterprise interfaces: user or workload identity, connector OAuth and per-tool OAuth for custom agents.

[Source: Google for Developers · Published 2026-11-20](https://developers.googleblog.com/how-to-handle-user-connector-and-agent-auth-in-gemini-enterprise-with-a-custom-ui/)

## Google describes distributed LLM training with Streaming DiLoCo in MaxText {#news-5}

Google says Streaming DiLoCo in MaxText trains across geographically distributed TPU slices by streaming parameter fragments rather than synchronizing full models at every step.

[Source: Google for Developers · Published 2026-11-19](https://developers.googleblog.com/distributed-llm-training-across-metros-streaming-diloco-in-maxtext/)

## Google outlines multi-turn agent training with Tunix and Gemma 4 {#news-6}

Google published a walkthrough for training a multi-turn, tool-using agent with Tunix and Gemma 4 on Cloud TPUs, using agentic GRPO and asynchronous vLLM rollouts.

[Source: Google for Developers · Published 2026-11-19](https://developers.googleblog.com/multi-turn-agentic-reinforcement-learning-with-tunix-and-gemma-4-on-google-tpus/)

## Google introduces ABFS for large Git repositories {#news-7}

Google describes Another Build File Service as an open-source content-addressable filesystem and build cache intended to accelerate work with massive Git repositories.

[Source: Google for Developers · Published 2026-11-17](https://developers.googleblog.com/accelerating-development-for-massive-git-repositories/)

## Apple updates App Store tax treatment and adds SaaS tax attribute {#news-8}

Apple says tax changes modified eligible app and in-app purchase proceeds in Botswana, Cameroon, Côte d'Ivoire and Rwanda. It also announced a new SaaS tax attribute.

[Source: Apple Developer · Published 2026-11-18 00:00:25 UTC](https://developer.apple.com/news/?id=4o5ie73a)

## Apple changes sensitive-access permissions in macOS 27.3 beta 2 {#news-9}

Apple says macOS 27.3 beta 2 splits Device Control and Data Access into System & App Protection Override and Accessibility, with more granular access guidance.

[Source: Apple Developer · Published 2026-11-16 16:00:11 UTC](https://developer.apple.com/news/?id=oqng0zjk)
