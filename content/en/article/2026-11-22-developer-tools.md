## Codex 0.171.0 adds model choices, default workspace and remote execution {#news-1}

Codex 0.171.0 adds GPT-6.2 Sol and Astra, with Sol the default catalog selection. It enables the TUI workspace by default and adds remote execution and remote-control commands.

## Google extends Agent Anomaly Detection to agents across clouds {#news-2}

Google says Agent Anomaly Detection now analyzes traces and logs from ADK agents on AWS, Azure or on-premises to detect behavioral risks without accessing their underlying runtime.

[Source: Google for Developers · Published 2026-11-20](https://developers.googleblog.com/agent-anomaly-detection-safeguarding-agents-across-other-clouds/)

## Google details private Cloud Run MCP connections for Gemini Enterprise {#news-3}

Google's guide explains private connections to internal Cloud Run MCP servers using Egress Agent Gateway, Private Service Connect, scoped DNS and dual-header OAuth 2.0.

[Source: Google for Developers · Published 2026-11-20](https://developers.googleblog.com/how-to-securely-connect-internal-cloud-run-mcp-servers-to-gemini-enterprise/)

## Google explains authentication layers for custom Gemini Enterprise UIs {#news-4}

Google's guide covers user authentication, federated connector OAuth and per-tool agent OAuth that developers must implement for custom Gemini Enterprise interfaces.

[Source: Google for Developers · Published 2026-11-20](https://developers.googleblog.com/how-to-handle-user-connector-and-agent-auth-in-gemini-enterprise-with-a-custom-ui/)

## Google describes distributed LLM training with Streaming DiLoCo in MaxText {#news-5}

Google says Streaming DiLoCo in MaxText streams parameter fragments across distributed TPU slices rather than synchronizing full models, reducing cross-slice communication.

[Source: Google for Developers · Published 2026-11-19](https://developers.googleblog.com/distributed-llm-training-across-metros-streaming-diloco-in-maxtext/)

## Google guides multi-turn agent training with Tunix and Gemma 4 {#news-6}

Google's tutorial uses Tunix, Gemma 4 and Cloud TPUs to train a tool-using agent, combining agentic GRPO with asynchronous vLLM rollouts.

[Source: Google for Developers · Published 2026-11-19](https://developers.googleblog.com/multi-turn-agentic-reinforcement-learning-with-tunix-and-gemma-4-on-google-tpus/)

## Apple updates App Store proceeds for tax changes {#news-7}

Apple says eligible app and in-app purchase proceeds changed for taxes in Botswana, Cameroon, Côte d'Ivoire and Rwanda. It also introduced a Software as a Service tax attribute.

[Source: Apple Developer · Published 2026-11-18 00:00:25 UTC](https://developer.apple.com/news/?id=4o5ie73a)

## Google introduces ABFS filesystem and build cache for large repositories {#news-8}

Google presents Another Build File Service, an open-source content-addressable filesystem and build cache intended to accelerate work on large Git repositories.

[Source: Google for Developers · Published 2026-11-17](https://developers.googleblog.com/accelerating-development-for-massive-git-repositories/)

## Apple refines powerful app permissions in macOS 27.3 beta 2 {#news-9}

Apple says macOS 27.3 beta 2 splits Device Control and Data Access into System & App Protection Override and Accessibility, and adds guidance for granting narrower app or folder access.

[Source: Apple Developer · Published 2026-11-16 16:00:11 UTC](https://developer.apple.com/news/?id=oqng0zjk)
