## Claude Code v2.1.305、サンドボックス設定追加とツール検索障害修正 {#news-1}

Claude Code v2.1.305はLinuxの入れ子ユーザー名前空間設定を追加。拒否されたツール検索なしで再試行し、設定やワークツリーの問題も修正する。

[出典: Anthropic Claude Code · 更新 2026-10-20 20:46:50 UTC](https://github.com/anthropics/claude-code/releases/tag/v2.1.305)

## Google、Coral NPUのアーキテクチャ完成とコンパイラ公開を発表 {#news-2}

Googleは行列実行ユニットでCoral NPUが完成したと説明。IREE/MLIRコンパイラはJAX、PyTorch、TensorFlowモデルを独自アセンブリなしで対応させる。

[出典: Google for Developers · 公開 2026-10-20](https://developers.googleblog.com/unifying-edge-ai-how-coral-npus-open-standard-brings-portable-energy-viable-intelligence-from-model-to-silicon/)

## Google、TorchTPUとTorchTitanの統合を解説 {#news-3}

GoogleはPyTorch向けTPUバックエンドと、SimpleFSDP、Graph Trainer、独自Pallasカーネルを備えたTorchTitanのTPU版を紹介した。

[出典: Google for Developers · 公開 2026-10-20](https://developers.googleblog.com/integrating-torchtpu-into-torchtitan-and-optimizing-models-for-tpu/)

## Google、TPU上のvLLMとSGLang向けPyTorchバックエンドを発表 {#news-4}

GoogleはTorchTPUを使うバックエンドを発表。最適化TPUカーネル、TPU SyncによるKVキャッシュ管理、分離型サービングに対応する。

[出典: Google for Developers · 公開 2026-10-20](https://developers.googleblog.com/announcing-new-vllm-and-sglang-inference-engines-on-tpu/)

## Google Model Explorer、独自コンパイラのグラフデバッグに対応 {#news-5}

Google AI Edge Model Explorerが独自コンパイラ中間表現とTOSA、VGF、PTEに対応。グラフ表示やノード別トレースでデバッグを支援する。

[出典: Google for Developers · 公開 2026-10-20](https://developers.googleblog.com/bringing-visual-graph-debugging-to-custom-edge-compilers-with-model-explorer/)
