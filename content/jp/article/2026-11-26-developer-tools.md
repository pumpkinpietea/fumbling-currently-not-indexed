## Claude Code v2.1.332、MCPサーバーのスキルとシェルコマンド用フックを追加 {#news-1}

## Claude Code v2.1.331、ターミナルのCode Mode対応を拡大 {#news-2}

Anthropicは複数のクラウド基盤でターミナルのCode Modeを追加し、claude doctorにAPI接続診断を導入した。

[出典: Anthropic Claude Code · 更新 2026-11-23 21:34:41 UTC](https://github.com/anthropics/claude-code/releases/tag/v2.1.331)

## Claude Code v2.1.330、企業組織へのサインインとeaselグラフ機能を追加 {#news-3}

Anthropicは企業管理コンソール配下の組織へのサインインと、対象プランのmacOS・Linux向けグラフ機能easelを追加した。

[出典: Anthropic Claude Code · 更新 2026-11-20 22:32:56 UTC](https://github.com/anthropics/claude-code/releases/tag/v2.1.330)

## Claude Code v2.1.329、フックの信頼確認とタスク管理を拡充 {#news-4}

Anthropicはフォルダーのフック定義元を示す確認画面を追加。/tasksに予約タスク、/loopの起動予定、目標、会話の分岐を表示する。

[出典: Anthropic Claude Code · 更新 2026-11-19 22:14:41 UTC](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)

## Claude Code v2.1.328、自動モードを拡大しMCPフック失敗時の処理阻止に対応 {#news-5}

AnthropicはOpus 4.6とSonnet 4.6の自動モードを拡大し、MCPツールのフック失敗時に処理を阻止する設定を追加した。

[出典: Anthropic Claude Code · 更新 2026-11-19 01:14:04 UTC](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)
