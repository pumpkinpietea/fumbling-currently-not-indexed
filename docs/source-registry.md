# Source discovery registry

The repository-owned [registry](../config/news-sources.json) preserves a broad candidate inventory. The developer wants flexible site positioning and as many relevant sources as practical. Registry inclusion is separate from access, model-input and public-output approval. See the [candidate findings](../specs/20-daily-publishing/source-candidates.md) and [requirements](../specs/43-source-registry/spec.md).

Nineteen reviewed feeds support private metadata collection;16 are selected for daily production. Active daily sources are ANTARA, JICA, JETRO, Viet Nam News economy/industries/Sci-Tech, Global Voices, ECNS, Mehr, Yahoo world/business/IT and Cabinet Secretariat of Indonesia headlines. CNA and ANTARA economy remain private metadata routes. Sources marked access_review remain visible but cannot be fetched by the collector. Feed IDs and URLs are reviewed repository configuration; input cannot supply arbitrary network addresses. Adding a source requires a PR and its own host/access review.

Use the existing npm run collect:feeds command with schemaVersion1, an explicit UTC window and a feeds array of enabled IDs. Each request selects at most16 distinct feeds, with no redirects/retries, a1MiB/200-item per-feed cap and a500-record total cap. Manual CLI defaults to sequential15-second retrieval; hourly/daily archive collection uses four concurrent8-second requests. A feed exceeding the remaining total cap is failed without keeping its records; the report remains incomplete. Required feeds reserve capacity before the three optional enrichment feeds; optional failures remain visible and cannot waive required-feed failures. See [source coverage](source-coverage.md) for current headline/schema, provenance, archive compatibility and actual replay evidence.

Every link is checked against its originating feed's host list before combined URL deduplication. Private reports preserve original URLs, original dates, record indices and feed IDs. JICA's older entries remain dated background candidates; retrieving them today does not make them fresh. Selection only establishes URL/date eligibility, not Southeast Asia relevance, IT/e-commerce classification, independent perspectives or article quality.

CNA's [official RSS page](https://www.channelnewsasia.com/rss) specifies personal non-commercial use; the trial is private metadata discovery. JICA's [official RSS directory](https://www.jica.go.jp/english/rss/index.html) supports feed discovery, with reuse subject to its site policy. Neither feed support nor successful retrieval approves body acquisition, model processing or public reproduction. No body, image, model call or publication is performed by this command. Automated use is separately configured per publisher and validated in the daily pipeline. Real reports stay outside Git, and printed CLI results contain aggregate counts only.

JICA's current Japanese news feed uses full English month names. A registry-selected adapter normalizes only those exact names before the existing strict calendar/timezone checks; raw pubDate values remain in the report. Default feed parsing remains strict. The old English feed directory currently redirects to archived 2023 material, so those routes are not enabled.

## Additional active adapters (#68)

The daily source policy supports JICA announcement titles only, Viet Nam News economy/industries official RSS excerpts, and Global Voices East Asia/technology excerpts. Viet Nam News UTF-16LE is accepted only for its explicit adapters, including its XML-prolog form without a BOM. Trusted Dublin Core creator fields are parsed only for Global Voices. Source validation binds feed ID, publisher, HTTPS host and article path.

Global Voices [CC BY attribution policy](https://globalvoices.org/about/global-voices-attribution-policy/) permits adaptations with author/source credit, license link and change indication. These appear before a derived summary. Its [AI policy](https://globalvoices.org/about/global-voices-policy-on-ai/) governs submissions on their site; no endorsement or partnership is implied. JICA feed descriptions are navigation, so only the dated title can ground a note. Viet Nam News provides [official RSS](https://vietnamnews.vn/rss); its [Privacy & Terms](https://vietnamnews.vn/privacy.html) retains copyright and supplies no blanket republication license. The selected scope is brief original factual reference to official feed evidence, with direct attribution, no article-body retrieval, images or copied paragraphs.

Reviewed 2026-10-11: [CNA RSS terms](https://www.channelnewsasia.com/rss/rssterms) prohibit third-party feed transfer, so CNA stays outside model input. [Al Jazeera terms](https://terms.aljazeera.net/index.html) restrict automated access; CGTN/Nikkei restrictions remain unresolved. NHK returned an access challenge. Xinhua's official RSS directory links to business/science feeds with 2017 entries, so they remain inactive. Keep these candidates visible without claiming they are active or routing around restrictions.

Real metadata check: all eight daily feeds succeeded with 151 records and 39 date/URL-eligible entries for the October 11 edition window. This verifies connectivity and metadata; it is not proof of independent perspectives or article accuracy. Activation evidence is tracked in specs/68-multiple-news-sources/tasks.md.

## Chinese and Middle Eastern adapters (#71)

ECNS (China News Service) and Mehr News Agency official RSS add publisher coverage without inferred viewpoint labels. ECNS has a strict feed-only +08:00 timestamp adapter and an exact-host HTTPS article-link upgrade; raw dates remain in private evidence. Its stale /rss.xml route is excluded. Mehr uses explicit GMT timestamps. Both supply RSS excerpt facts only, with original attribution and no bodies/images. See [low-cost discovery options](news-discovery.md) for Google News RSS, optional Feedly Free OPML and manual original URLs. Google/Feedly discovery is not automatically wired into daily evidence.
