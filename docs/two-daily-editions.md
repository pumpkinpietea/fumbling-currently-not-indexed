# Two daily editions

Issue: https://github.com/pumpkinpietea/fumbling-currently-not-indexed/issues/89

The confirmed scope is Indonesia general news across all topics, plus Southeast Asia IT, e-commerce and digital economy INCLUDING Indonesia. Indonesia technology events can appear in both pages. The shared event is generated and reviewed once, then rendered with identical localized title/summary in both editions. General foreign/world news without SEA technology relevance is excluded. Geography and topic keyword matching only shortlists candidates; skeptical source review still has to establish actual relevance.

The existing Jakarta 07:30 collector runs once; the protected publication workflow follows it at 07:45 (Actions scheduling/deployment can delay availability). A successful complete run prepares four new files: EN/JP date-indonesia-news.md and EN/JP date-southeast-asia-tech.md. Each page uses its own translation key and stable dated slug. The first unattended scheduled run still needs observation; a private advance-clock rehearsal is not proof of tomorrow's execution.

Historical Indonesia digests informed the structure: up to three linked highlights followed by detailed factual notes and original sources with publisher-country badges. Highlights reuse the same approved summaries, rather than a second model-written interpretation. Explicit news-N anchors keep directory and home links pointed at the news item rather than the highlights heading. The new pages do not reproduce speculative impact/confidence boilerplate or unrelated old world news. Existing historical articles are preserved.

A complete collection with no eligible stories produces a dated page explicitly stating that no new eligible stories were found in that collection window. This is not a claim that no real-world news occurred. No sources means zero AI calls. Failed collection, invalid generation, failed review or existing date/file conflicts still prevent publication; they are not mislabeled as empty news days. Replay/date locks prevent overwriting existing editions. Private trial locks and retained bundles include the runtime revision prefix so rollout checks preserve earlier evidence.

## Bounds and publication contract

One generation and one skeptical review cover both topics, at most five unique events, at most four selected sources, zero retries and the existing 600-second/one-task job. Reserve two candidate slots per topic and fill remaining slots only for publisher diversity. Reviewed excerpts are capped at 1200 characters / 1600 bytes, except unchanged title-only institutional evidence. Send only grounding fields to the model, retaining full provenance privately; short summaries and one quote per source keep requests within the existing 16 KiB transport limit, which fails closed on oversized requests. No paid inference fallback or new cloud resources are added. The existing maximum runtime/resource spending envelope is unchanged; total GCP spending still depends on other project/account usage.

New bundle schema 2 binds the four exact rendered files, review, dates, original evidence and shared events. Schema 1 remains accepted for retained old two-file bundles without changing their rendering. Consumer staging, already-published checks, PR scope verification and draft rehearsals use the exact reconstructed file set, not a general path allowance. Publication remains feature/content branch, required exact-head CI, protected squash merge, main validation and Hosting delivery.

Google personal discovery now runs five bounded queries: SEA tech, Chinese/Middle Eastern coverage of Indonesia general or SEA tech, Indonesia general, explicit Japanese Yahoo Indonesia discovery, and one rotating local-language tech query. Each gets up to 30 candidates, with 150 total, preventing earlier queries from exhausting all capacity. Yahoo results remain private Google-discovered links; Yahoo article bodies are not fetched or automatically used as public evidence. Public notes still use the reviewed official RSS source registry, including ANTARA general top news. Other private discovery uses the same inclusive scope.
