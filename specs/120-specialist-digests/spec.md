# Specialist news requirements

Issue: https://github.com/pumpkinpietea/fumbling-currently-not-indexed/issues/120

## Goal and authority
The owner requests separate worldwide cybersecurity and developer-tool EN/JP summaries, including Japan/US/China coverage, evidence-linked world trends and social discovery for both fields. Publish only October17 pages for the first edition, following existing protected release authority.

## Acceptance criteria
1. Implement a repeatable bounded collector for independently configured specialist streams using reviewed official institutional/vendor feeds and update pages. Preserve source dates, evidence hashes, URLs, publisher geography and collection failures; no geographic restriction inherited from SEA editions.
2. Collect measurable social discovery for both streams, including developer tools (Claude Code/Codex/DeepSeek/Google/Apple), with explicit query/time/platform/count coverage. Social text is discovery only; no inferred global popularity or unsupported product/attack facts. Original source validation is required.
3. Render two distinct EN/JP article pairs only from populated independently reviewed selections, preserving dates/attribution and original links. Cyber trend observations cite selected evidence and distinguish vulnerabilities/advisories, confirmed incidents and attributed allegations. No invented country ranking or actor attribution.
4. Verify live retrieval and original facts; publish only October17 specialist articles using actual publication time and an explicit recent-source interval. Do not modify other dates or existing daily content/state.
5. Remain within existing solo cost boundaries: reusable local commands, no new paid services/model fallback/cloud resources. At most three existing-plan calls for this operator edition, zero transport retries. The originally planned two-call budget was revised after the first generation hit its stream bound and the independent review identified correctable factual wording; one final corrected-candidate review is allowed. Automated daily limits remain two calls. Existing daily automation runtime/model/scheduler caps are unchanged; autonomous scheduled specialist publishing is not claimed by the first manual edition. Record collection cadence and this activation boundary explicitly.
6. Meaningful parser/date/provenance/social-separation/dedup/partial-failure/render tests, CI, full staged privacy review, actual bilingual browser inspection and live smoke verification before completion.

## Design
Use a separate specialist source registry and reusable secure transport (public DNS, HTTPS, no redirects, finite bytes/time/concurrency). RSS2/RDF/Atom and narrowly selected official update pages supply bounded evidence. Independent social discovery uses public Hacker News search and official-account/update links without paid accounts or login scraping. Local private reports remain outside Git and contain no credentials. Source rights/access review precedes adoption; unsupported/restricted sources remain inactive with evidence. Publication follows branch/PR/exact-head CI/main Hosting. Detailed requirements, design and tasks live alongside this specification.
