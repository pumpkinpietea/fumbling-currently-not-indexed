# Design

Issue: https://github.com/pumpkinpietea/fumbling-currently-not-indexed/issues/123

Keep legacy RSS parsing, source selection and schemas 1–5 intact. Schema 6 wraps a validated schema 5 daily portion plus a specialist candidate/report, and binds the combined source list, events, independent review and exactly reconstructed files. One generation response contains legacy daily events, specialist events and cited cyber observations; one skeptical review checks the whole response. Consumers reconstruct both portions before any content-only PR.

Daily specialist selection rotates fairly between security/developer and original publishers, reserves capacity for both existing topics, then fills unused capacity up to 40 sources. Use seven calendar UTC dates ending before editionDate, not a claim of seven complete days. Source records retain date precision; missing/partial archive slots are explicit. Selected official evidence alone enters model context; social discovery never enters model context. Exact original URL history is conservative across updated pages.

Hourly specialist objects are independent of legacy 500-record/1 MiB objects, bounded to 500 records/1 MiB, create-only and retained under existing evidence lifecycle. Validate registry identity, canonical evidence and feed identities/counts. Read at most 32 recent hourly slots. Invalid retained evidence fails closed; network failures remain isolated and reported. Social queries rotate one security plus one developer query per hour with eight-second bounds, private output only.

Generation asks for compact JSON, brief original summaries and grounding quotes, ASCII ordinal quantities, no unsupported cyber geography/rankings. Existing 192 KiB request, 256 KiB output, 1 MiB SSE and 240 seconds/call remain fail-closed. The 40-source capacity is not a promised daily output quota. The global task remains 600 seconds; hourly capture application timeout becomes 110 seconds with zero inference.

## Cost scenario (verified 2026-10-18)

Reuse existing Cloud Run job/Scheduler, bucket, GitHub Free public-repository CI, app-specific ChatGPT plan integration and IAM. No new service, subscription or paid model fallback. Official pricing: https://cloud.google.com/run/pricing and https://cloud.google.com/storage/pricing . us-central1 jobs cost USD0.000018/vCPU-second and USD0.000002/GiB-second, with shared monthly allowances of 240,000 vCPU-seconds/450,000 GiB-seconds and one-minute minimum per job. At 744 hourly executions/month, an additional conservative 40 seconds each costs approximately USD0.57 before shared allowances; 512 MiB RAM included. Separate <=1 MiB/hour official snapshots retain <=336 MiB for 14 days; two-query social evidence is additionally bounded to <=128 KiB/hour (~42 MiB retention). Daily 32 archive reads add at most 992 reads/month; snapshot/social writes <=1,488/month. Include operation, storage, logging, image retention and network uncertainty; expected incremental total <=USD1/month under these assumptions, not a spending cap. Existing total GCP spend remains unmeasured; preserve the approved USD10/month total constraint and existing bounded logs/14-day evidence. No model-call frequency increase. One finite two-call private rehearsal uses the same plan limits and no paid credits.

GitHub visibility was rechecked as PUBLIC/isPrivate=false on 2026-10-18. Existing standard Ubuntu hosted validation/build workflows remain unchanged; public-repository standard hosted runners are free under https://docs.github.com/en/billing/concepts/product-billing/github-actions . No paid protection, larger runner or GitHub plan feature is introduced.

Private replay verification deliberately includes already-published specialist notes only in the rehearsal to exercise all four topic renderers. This is explicitly not proof of new eligible security coverage; a separate unchanged-history metadata trial verifies exclusion. Five real-source events passed two existing-plan calls and operator excerpt inspection. Maximum-load 40-story model output remains unverified. The replay uses a private fixture revision identifier, never an approved production revision; its request/output/status and dirty working-tree test context are retained privately.
