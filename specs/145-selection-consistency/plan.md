# Design

Add an opt-in milestone numeric policy threaded only through schema 8 daily reconstruction. English ordinal words in bounded institutional strategy/policy/plan contexts and Japanese first-milestone expressions normalize to exact ordinal digits. Leave time/ambiguous ordinary words unchanged.

Extend the item-review envelope in schema 8 with `previousEvents` and `duplicateEvidence`. Decisions retain candidate ID/digest/approval/reason and add nullable `duplicateOf`. Validate exact history links and reject approval of a duplicate. Schemas 6/7 continue using their original reconstruction mode.

Use SHA-256 of URL, publication time and excerpt hash as the duplicate identity. Read validated optional identities from existing prepared run records without additional GCS requests. Filter both daily and specialist evidence before fair allocation; persist counts in existing private selection evidence. Bind the prior fingerprint set into the schema 8 bundle, and recheck it in item preflight. Record newly rejected duplicate fingerprints separately from published source URLs and event hints. Store only direct per-run decisions, not inherited fingerprints, to preserve the 14-date expiry.

No services or model calls are added. Existing state retention and runtime limits apply. Metadata-only rollout verification uses existing resources and zero inference. This repair does not promise broad publisher coverage or factual model accuracy, and does not backfill historical rejection memory.
