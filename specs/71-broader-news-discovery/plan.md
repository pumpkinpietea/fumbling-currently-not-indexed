# Design and tasks

1. Record source/access research and free discovery tradeoffs before implementation.
2. Add ECNS and Mehr registry entries, feed-local timestamp/URL normalization and bounded collection capacity.
3. Add focused adapter/provenance regressions and perform real metadata retrieval.
4. Render the existing source-reviewed bilingual note as ordinary operator-controlled news content; preserve private runtime state.
5. Review staged/outgoing privacy, pass CI, merge, build/deploy immutable runtime and verify cloud collection and live content.

Feedly Free is optional source-list management via OPML, not the unattended runtime dependency. Google News RSS is useful to discover wider original sources; its wrapper URLs and search-index timestamps cannot pass the current publisher-evidence contract. Start with private/manual discovery and adopt verified official feeds; specify a separate discovery adapter before any automatic Google candidate ingestion. No paid search or aggregation service is provisioned.
