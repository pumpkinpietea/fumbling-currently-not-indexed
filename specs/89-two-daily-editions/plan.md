# Design

Keep one shared source pool, one generation and one skeptical review, not separate model calls per edition. Lexical Indonesia/SEA-tech scope is a conservative candidate boundary; model review must confirm actual subject relevance. Render the approved shared events into Indonesia-general and inclusive SEA-tech pages. A shared Indonesia tech event is rendered identically into both. Each page starts with up to three factual linked highlights using the same approved text and stable explicit item anchors; no unsupported impact/confidence boilerplate.

Use bundle schema 2 for four exact files and allow empty page events after complete collection. Preserve schema 1 validation for retained old bundles. Restrict publisher diff/PR counts to the exact renderer output and support both two/four-file contracts, including draft rehearsals. Keep the existing production run/date locks and revision-scoped private trials, two model calls, five unique events, 600-second job and zero retries. Select at most four sources with reserved general/tech slots and limit each excerpt to 1200 characters / 1600 bytes (title-only announcements stay unchanged) before inference to remain within the existing 16 KiB transport cap. Metadata trials still cannot access app auth.

Google discovery adds fixed Indonesia-general and Japanese Yahoo queries with bounded per-query quotas; all reader candidates remain private and never become model evidence automatically. Existing reviewed official feeds supply public factual notes. Use the existing ANTARA general top-news feed without increasing daily official feeds. Scope changes also apply to other private discovery. Retain source-date windows, licensed attribution and original links.

Preview both layouts using a sanitized synthetic fixture outside Git, with actual screenshot inspection and live generic empty-page preview only if necessary. Never publish synthetic fixture content or advance-clock trial results. Deploy the validated immutable runtime after main CI/build and run a private next-day rehearsal without changing production date state.
